# สัปดาห์ที่ 8 ตรวจความก้าวหน้าโครงงาน

อ่านใบงานที่ 8 ในหนังสือ ภาคผนวก ฉ งานสัปดาห์นี้ทำในคลังโครงงานของกลุ่ม ไม่ได้ทำในโฟลเดอร์นี้

1. สมาชิกหนึ่งคนสร้างคลังโครงงานชื่อ `ชื่อร้าน-shop` (อังกฤษตัวพิมพ์เล็ก) แบบ Public ติ๊ก Add a README file เพิ่มสมาชิกเป็นผู้ร่วมงาน แล้วเปิด GitHub Pages
2. ลากไฟล์ข้างในโฟลเดอร์ `week07` ของสมาชิกหนึ่งคน (`index.html` `style.css` `app.js` และโฟลเดอร์ `images`) ไปวางที่ชั้นนอกสุดของคลังโครงงาน
3. เขียน `README.md` ของคลังโครงงาน: ชื่อร้านและสิ่งที่ขาย ลูกค้าหลักและงานหลัก ลิงก์ต้นแบบ Figma ลิงก์หน้าร้าน สมาชิกและหน้าที่ และผลตรวจตนเองตามตารางในใบงาน
4. นำเสนอกลุ่มละ 3 นาทีจากลิงก์ GitHub Pages บนมือถือ
5. สมาชิกทุกคนใส่ลิงก์คลังโครงงานกลุ่มในบรรทัดท้ายของไฟล์นี้ แล้วคอมมิต ผู้สอนใช้ลิงก์นี้หาคลังโครงงาน

ข้อมูลร้าน เบอร์โทร เบอร์พร้อมเพย์ และ LINE ID ต้องเป็นข้อมูลสมมติ

ลิงก์คลังโครงงานกลุ่ม: https://github.com/<ชื่อผู้ใช้ของคนที่สร้าง>/<ชื่อร้าน>-shop
