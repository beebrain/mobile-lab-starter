# สัปดาห์ที่ 5 หน้าแรกของร้านด้วย HTML

อ่านใบงานที่ 5 ในหนังสือ บทที่ 4

1. เปิดไฟล์ `index.html` แล้วทำตาม TODO 1-4
2. รูปของร้านให้อัปโหลดลงโฟลเดอร์ `images` ตั้งชื่อเป็นภาษาอังกฤษตัวพิมพ์เล็ก ไม่เว้นวรรค เช่น `shop.jpg`
3. คอมมิต แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/mobile-lab/week05/` บนมือถือ
4. ส่วนท้าทาย: สร้าง `about.html` และลิงก์ไปมาระหว่างสองหน้า
5. คอมมิต แล้วอัปโหลดภาพหน้าจอบนมือถือลงโฟลเดอร์ `week05` (Add file > Upload files ในหน้าโฟลเดอร์บน github.com)

ใช้ข้อมูลสมมติเท่านั้น ห้ามใส่เบอร์โทรหรือที่อยู่จริงของใคร
