# mobile-lab-starter

โค้ดตั้งต้นรายสัปดาห์ของวิชา 3603403 โปรแกรมอุปกรณ์สื่อสารเคลื่อนที่ทางธุรกิจดิจิทัล
(Mobile Programming and Applications in Digital Business) มหาวิทยาลัยราชภัฏอุตรดิตถ์

## เริ่มต้น (ทำครั้งเดียวในสัปดาห์ที่ 1)
1. เข้าสู่ระบบ GitHub กดปุ่ม **Use this template** > **Create a new repository** (ห้ามเลือก Open in a codespace)
2. ตั้งชื่อคลัง `mobile-lab` เลือก **Public** แล้วกด Create repository
3. ในคลังของตนเอง: Settings > Pages > Branch เลือก `main` และ `/ (root)` > Save
4. รอสักครู่ แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/mobile-lab/` บนมือถือ

## ทำงานแต่ละสัปดาห์
เปิดคลัง `mobile-lab` ของตนเอง กดแป้นจุด (`.`) เพื่อเปิด github.dev แก้ไฟล์ในโฟลเดอร์ของสัปดาห์ตามใบงาน แล้วคอมมิตก่อนจบคาบ
แต่ละโฟลเดอร์มี `README.md` บอกสิ่งที่ต้องทำ รายละเอียดอยู่ในใบงานของหนังสือ

| สัปดาห์ | โฟลเดอร์ | เรื่อง |
|---|---|---|
| 1 | `week01` | สำรวจสิทธิ์ของแอป |
| 2 | `week02` | เลือกอุปกรณ์และรูปแบบแอป |
| 3 | `week03` | ไวร์เฟรมกระดาษ |
| 4 | `week04` | ต้นแบบ Figma |
| 5 | `week05` | หน้าเว็บแรกด้วย HTML |
| 6 | `week06` | แต่งหน้าร้านด้วย CSS |
| 7 | `week07` | ปุ่มเพิ่มลดจำนวน |
| 8 | `week08` | ตรวจความก้าวหน้าโครงงาน (ทำในคลังโครงงานกลุ่ม) |
| 9 | `week09` | รายการสินค้าจากอาร์เรย์ |
| 10 | `week10` | ตะกร้าที่จำค่าได้ |

| 14 | `week14` | นโยบายความเป็นส่วนตัว |
