(ใส่ภาพหน้าจอบนมือถือ 3 ภาพ: รายการสินค้า ตะกร้าและ QR ส่งออเดอร์ แทรกภาพด้วย ![คำอธิบาย](ชื่อไฟล์รูป.png))

## ความสามารถของหน้าร้าน
- [ ] แสดงสินค้าจากอาร์เรย์
- [ ] ตะกร้าที่จำค่าได้ เพิ่มและลบสินค้าได้
- [ ] QR พร้อมเพย์ตามยอดตะกร้า
- [ ] ส่งออเดอร์ทาง LINE และปุ่มคัดลอก
- [ ] โทรหาร้าน นำทาง แนบสลิป
- [ ] ติดตั้งบนจอโฮมได้
- [ ] นโยบายความเป็นส่วนตัวและช่องติ๊กตาม PDPA
