# สัปดาห์ที่ 15 นำเสนอโครงงานบนมือถือจริง

อ่านใบงานที่ 15 ในหนังสือ ภาคผนวก ฉ งานสัปดาห์นี้ใช้คลังโครงงานของกลุ่ม ไม่ได้ทำในโฟลเดอร์นี้

ก่อนวันนำเสนอ คลังโครงงานต้องมีงานจากใบงานที่ 14 ครบ และ README มีหัวข้อตามแม่แบบใน `week14/README.md` ผู้สอนตรวจคลังตามสภาพในวันก่อนนำเสนอ

ลำดับการนำเสนอ (กลุ่มละ 10 นาที)
1. (2 นาที) ร้าน ลูกค้า และปัญหาที่หน้าร้านช่วยแก้
2. (5 นาที) สาธิตบนมือถือจริง: เปิดจากจอโฮม เลือกสินค้า ใส่ตะกร้า QR พร้อมเพย์ ส่งออเดอร์ทาง LINE ปุ่มโทร นำทาง แนบสลิป และหน้านโยบายความเป็นส่วนตัว
3. (1 นาที) สิ่งที่ยังไม่ทำงาน และตัวชี้วัดถ้าร้านใช้จริง
4. (2 นาที) ตอบคำถาม สมาชิกทุกคนตอบอย่างน้อยหนึ่งข้อ

สิ่งที่ส่ง: คอมมิตงานในคลังโครงงานก่อนวันนำเสนอ และแบบประเมินกลุ่มอื่นของแต่ละคน (ท้ายคาบ ถ้ากรอกในเล่มให้ถ่ายรูปแล้วอัปโหลดลงโฟลเดอร์ `week15` นี้)
