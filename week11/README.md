1. คัดลอกอาร์เรย์ `products` และรูปของร้านกลุ่มจาก `week10` มาแทนของร้านตัวอย่าง แก้ชื่อร้านใน `<title>` และ `<h1>` ของ `index.html` และชื่อร้านกับช่องทางติดต่อ (สมมติ) ใน `privacy.html`
2. TODO 1 (`app.js`): LINE ID สมมติของร้านกลุ่ม คงเบอร์พร้อมเพย์สมมติ `0800000000` ไว้
3. TODO 2 (`index.html`): เบอร์โทรสมมติและปลายทางแผนที่ของร้าน และเพิ่ม `accept="image/*"` ในช่องแนบสลิป
4. TODO 3 (`app.js`): ใน `showCheckout` เรียก `makePromptPayQR(PROMPTPAY, total, "qr")`
5. TODO 4 (`app.js`): ลิงก์ส่งออเดอร์ทาง LINE ที่เข้ารหัสด้วย `encodeURIComponent`
6. TODO 5 (`app.js`): ปุ่มส่งออเดอร์ใช้ได้เมื่อมีสินค้า **และ** ติ๊กช่องรับทราบนโยบาย
7. คอมมิต เปิดลิงก์ `week11` บนมือถือ ทดสอบตามรายการในใบงาน (สแกน QR ด้วยแอปธนาคารแต่ห้ามโอน) แล้ว Sign out
