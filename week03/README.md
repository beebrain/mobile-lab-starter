# สัปดาห์ที่ 3 ไวร์เฟรมกระดาษของร้านกลุ่ม

อ่านใบงานที่ 3 ในหนังสือ บทที่ 3 ชื่อ-สกุล:

## ผู้ใช้หลักและงานหลัก
- ผู้ใช้หลักของร้าน: (เขียน 1-2 ประโยค)
- งานหลักที่ลูกค้ามาทำในแอป: (เขียน 1-2 ประโยค)

## ไวร์เฟรม 4 หน้าจอ
1. บนมือถือ: เปิด github.com > mobile-lab > week03 > Add file > Upload files > Commit changes
2. บนคอมพิวเตอร์: เปิด github.dev คลิกขวาที่รูปแต่ละรูป > Rename เป็น screen1.jpg ถึง screen4.jpg (ถ้านามสกุลเดิมเป็น .jpeg หรือ .JPG ให้พิมพ์เป็น .jpg ได้เลย ไม่ต้องแก้บรรทัดรูปด้านล่าง)
3. คลิกเปิดไฟล์ README.md นี้ แล้วกด Ctrl+Shift+V ตรวจว่ารูปด้านล่างขึ้นครบ
4. ไปที่แท็บ Source Control ทางซ้าย พิมพ์ข้อความคอมมิต แล้วกด Commit & Push
