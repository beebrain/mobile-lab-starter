# สัปดาห์ที่ 7 ปุ่มเพิ่มลดจำนวนและคำนวณราคา

อ่านใบงานที่ 7 ในหนังสือ บทที่ 5

1. ลองทำก่อน: แก้ `try/app.js` แล้วดูผลในคอนโซล (เปิด `https://<ชื่อผู้ใช้>.github.io/mobile-lab/week07/try/` แล้วกด F12 หรือ Ctrl+Shift+I)
2. แก้ชื่อสินค้า ราคา และรูปใน `index.html` เป็นสินค้าของร้านกลุ่ม
3. ทำ TODO 1-3 ใน `app.js`
4. ทดสอบ: กดบวก 3 ครั้ง ยอดต้องเท่ากับราคา x 4 (ถ้าทำส่วนท้าทายแล้ว ยอดจะเป็นราคาที่ลด 10%) / กดลบ 5 ครั้ง จำนวนต้องเหลือ 1
5. เปิดคอนโซลไว้เสมอ ถ้ามีข้อความสีแดง อ่านเลขบรรทัดแล้วแก้
6. คอมมิต ส่งลิงก์ `https://<ชื่อผู้ใช้>.github.io/mobile-lab/week07/` และภาพหน้าจอบนมือถือหลังกดบวก 3 ครั้ง ในช่องทางส่งงานที่ผู้สอนกำหนด
