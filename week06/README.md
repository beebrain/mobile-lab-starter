# สัปดาห์ที่ 6 แต่งหน้ารายการสินค้าด้วย CSS

อ่านใบงานที่ 6 ในหนังสือ บทที่ 4

1. คัดลอกเนื้อหาร้านจาก `week05` มาใส่ใน `index.html` และใส่รูปสินค้า 3 รูปในโฟลเดอร์ `images` (ชื่อ `product1.jpg` ถึง `product3.jpg` หรือแก้ชื่อใน `src` ให้ตรง)
2. ทำตาม TODO 1-4 ใน `style.css`
3. ตรวจด้วยโหมดจำลองมือถือของ Chrome (F12 แล้ว Ctrl+Shift+M) และบนมือถือจริง
4. คอมมิต แล้วอัปโหลดภาพหน้าจอบนมือถือกับภาพต้นแบบ Figma หน้าเดียวกันลงโฟลเดอร์ `week06` (Add file > Upload files ในหน้าโฟลเดอร์บน github.com)
5. ส่วนท้าทาย: จอกว้างตั้งแต่ 600 พิกเซล แสดงการ์ด 2 คอลัมน์
