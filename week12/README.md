# ใบงานที่ 12 หน้าแรกของแอปร้านด้วย Flutter

ห้องปฏิบัติการไม่มี Flutter ในเครื่อง จึงเขียนและดูผลใน DartPad แล้วเก็บงานในคลังนี้

1. เปิด `dartpad.dev` เลือก New > Flutter ลบโค้ดเดิมทั้งหมด
2. คัดลอกทุกบรรทัดจาก `week12/lib/main.dart` ไปวางใน DartPad แล้วกด Run ต้องเห็นแถบด้านบนชื่อ ร้านของฉัน
3. ทำ TODO 1-6 ทีละข้อ กด Run หลังแต่ละข้อ (ดูตัวอย่างในบทที่ 8 หัวข้อ 8.3)
4. ย่อหน้าต่างเบราว์เซอร์ของ DartPad บนคอมพิวเตอร์ให้แคบเท่าจอมือถือ ตรวจว่าไม่มีแถบลายเหลืองดำ และปุ่มไม่ล้นจอ
5. คัดลอกโค้ดจาก DartPad กลับมาวางทับ `week12/lib/main.dart` ใน github.dev แล้วคอมมิต `week12: home page`
6. อัปโหลดภาพหน้าจอ DartPad ที่เห็นแอปทางขวาลงโฟลเดอร์ `week12` (ไม่ต้องส่งลิงก์ ผู้สอนตรวจจากคลัง) แล้ว Sign out

ส่วนท้าทาย: เพิ่มแถวเวลาเปิดร้านใต้ข้อความแนะนำ (Icon(Icons.schedule) + Text) และทำให้แถวปุ่มไม่ล้นจอเมื่อเพิ่มปุ่มที่สาม ส่งข้อความ ด้วย Wrap

ห้ามลบบรรทัด `class ShopApp` เพราะไฟล์ทดสอบและสัปดาห์ 14 ใช้ชื่อนี้
