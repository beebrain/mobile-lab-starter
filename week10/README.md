# สัปดาห์ที่ 10 ตะกร้าสินค้าที่จำค่าได้

อ่านใบงานที่ 10 ในหนังสือ บทที่ 6

1. คัดลอกอาร์เรย์ `products` จาก week09 แก้ชื่อร้านใน `<h1>` และ `<title>` (ถ้าใช้รูปจริง ลากไฟล์รูปมาวางใน `week10/images`)
2. ทำ TODO 1-3 ใน `app.js`
3. คอมมิต แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/mobile-lab/week10/` ใน Chrome บนคอมพิวเตอร์
4. ทดสอบ: ใส่สินค้า A สองครั้ง B หนึ่งครั้ง / โหลดหน้าใหม่ ตะกร้าต้องยังอยู่
5. ล้างตะกร้า: F12 > Application > Local storage > ลบ cart (บนมือถือใช้แท็บไม่ระบุตัวตนแทน)
6. ถ้าแก้ id ของสินค้าหลังเคยใส่ตะกร้า ให้ลบ cart ก่อน มิฉะนั้นคอนโซลจะแจ้ง TypeError
7. เปิดบนมือถือ ถ่ายภาพหน้าจอที่เห็นตะกร้าอย่างน้อย 2 รายการพร้อมยอดรวม อัปโหลดลงโฟลเดอร์ `week10` (Add file > Upload files ในหน้าโฟลเดอร์บน github.com) แล้วออกจากระบบ GitHub

ส่วนท้าทาย: เขียนจำนวนชิ้นรวมลง `<span id="cart-count">` เช่น (3 ชิ้น)
