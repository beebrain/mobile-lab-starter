# ใบงานที่ 14 build APK และติดตั้งบน Android

โค้ดในโฟลเดอร์นี้ build ผ่านทันที ถ้าจะใช้โค้ดใบงานที่ 13 ของตน ต้องรันใน DartPad ผ่านก่อน แล้วจึงวางทับ `week14/lib/main.dart`

1. ใน github.dev (ไม่ใช่ DartPad) เปิด `week14/android/app/src/main/AndroidManifest.xml` แก้ TODO 1 `android:label` เป็นชื่อร้านของกลุ่ม
2. เปิด `week14/pubspec.yaml` แก้ TODO 2 เลขรุ่นเป็น `1.0.1+2`
3. คอมมิต `week14: build apk` แล้วเปิดแท็บ Actions ของคลังบน github.com รอ 5-8 นาที
   - เครื่องหมายถูกสีเขียว: สำเร็จ ไปข้อ 4
   - กากบาทสีแดง: คลิกงานนั้น อ่านหน้าสรุปที่บอกไฟล์และบรรทัดที่ผิด แก้ใน DartPad ให้ผ่าน แล้วคอมมิตใหม่
4. บนมือถือ Android เปิด `github.com/<ชื่อผู้ใช้>/mobile-lab/releases` แตะ `app-release.apk` เพื่อดาวน์โหลด
5. แตะไฟล์ที่ดาวน์โหลด ถ้าเครื่องถาม ให้อนุญาตให้เบราว์เซอร์ติดตั้งแอปจากแหล่งนี้ (Install unknown apps) แล้วติดตั้ง
6. ทดสอบตามรายการในใบงาน: ชื่อใต้ไอคอน รูปสินค้าขึ้น เพิ่มสินค้าแล้วยอดถูก หมุนจอแล้วยังใช้ได้
7. ถ่ายภาพจอโฮมที่มีไอคอนแอป (ไม่ให้เห็นข้อมูลส่วนตัว) อัปโหลดไว้ในโฟลเดอร์ `week14` (ชื่อไฟล์เดิมจากมือถือได้) เขียนผลทดสอบข้อ 6 ต่อท้ายไฟล์นี้ คอมมิต แล้ว Sign out (ไม่ต้องส่งลิงก์ ผู้สอนตรวจหน้า Releases ของคลังเอง)

ผู้ใช้ iPhone: ติดตั้งบนเครื่อง Android ของคู่หรือเครื่องสำรองของผู้สอน
APK นี้ลงชื่อด้วยกุญแจทดสอบ ใช้ในชั้นเรียนได้ แต่ส่งขึ้น Google Play ไม่ได้

ส่วนท้าทาย: ไอคอนแอปของร้าน อัปโหลดรูป PNG ขนาด 192x192 ชื่อ `ic_launcher.png` ไว้ใน `week14/android/app/src/main/res/` โฟลเดอร์ `mipmap-mdpi` `mipmap-hdpi` `mipmap-xhdpi` `mipmap-xxhdpi` `mipmap-xxxhdpi` ทั้งห้าโฟลเดอร์ แล้วเพิ่มเลขรุ่นเป็น `1.0.2+3` และคอมมิตใหม่
