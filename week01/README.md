# สัปดาห์ที่ 1

อ่านใบงานที่ 1 ในหนังสือ บทที่ 1

1. แก้ชื่อใน `index.html` (บรรทัดใต้หมายเหตุ TODO เปลี่ยน ... เป็นชื่อเล่นและสาขา) แล้วคอมมิต
2. รอประมาณ 1 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/mobile-lab/week01/` บนมือถือ และแตะลิงก์ดูแอปร้านตัวอย่าง
3. กรอก `permissions.md` แล้วคอมมิต
4. คอมมิตหน้าเว็บและ `permissions.md` ภายในเวลาคาบ ผู้สอนตรวจจากคลังของคุณโดยตรง ไม่ต้องส่งลิงก์
5. ออกจากระบบ GitHub ก่อนลุกจากเครื่อง
